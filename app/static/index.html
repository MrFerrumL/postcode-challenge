Bus Factor — число уникальных сотрудников с заявленным навыком. 0 — нет покрытия, 1 — единственный носитель. Доля ставки учитывается отдельно.

Закрыть спринт и пересчитать будущее

Внесите подтверждённые завершения и новые оценки оставшейся работы. Задачи без записи сохраняют прежний остаток. Закрытие спринта подтверждает, что других завершений не было.

В форме оставьте только обновляемые задачи. Для Done задайте нулевые остатки. Для InProgress укажите остаток по каждой роли и remaining_sp. spent_hours — фактические часы этого спринта, они не вычитаются из уже указанного остатка повторно.

Данные и горизонт

Загрузка создаёт новый сценарий. Предыдущие планы остаются в списке сверху.

При строгой проверке задача без требований к нужной роли не включается в план. В обычном режиме проверяются роли и часы; соответствие неизвестному стеку не подтверждено.

Изменить доступность

Коэффициент уменьшает часы сотрудника во всех его командах в выбранном спринте.

0 — недоступен, 0,5 — половина обычного времени, 1 — обычная доступность.

Уточнить задачу

После внесения факта остатки изменяются через форму последнего спринта. Исходный Excel не меняется.
